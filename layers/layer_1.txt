# Layer 1 – Thu thập dữ liệu (Data Acquisition)

**Các file**
- `download_datasets.py` : tải Kaggle datasets (vn_trash, garbage_v2). **Input**: tùy chọn `--output-dir`. **Output**: dữ liệu gốc trong `data/external/` + manifest.
- `download_100_waste_images.py` : tìm kiếm và tải 100 ảnh đa lớp. **Input**: danh sách query (cố định). **Output**: ảnh trong `data/holdout/` + `manifest_100_anh_online.json`.
- `download_and_qa_minibatch01.py` : kiểm tra SHA‑256/pHash ảnh thô. **Input**: `data/raw/`. **Output**: ảnh sạch trong `data/processed/minibatch01/` + manifest QA.
- `download_and_scan_test_images.py` : quét metadata ảnh holdout. **Input**: `data/holdout/`. **Output**: CSV `holdout_scan_report.csv`.
- `search_candidates.py` : tạo danh sách URL cho mỗi lớp. **Input**: query hard‑code. **Output**: `candidate_urls.json`.
- `test_queries.py` : kiểm thử số URL trả về. **Input**: `queries.yaml`. **Output**: không tạo file (PyTest).
- `verify_and_download_candidates_100.py` : tải và xác thực 100 candidate. **Input**: `candidate_urls.json`. **Output**: 100 ảnh trong `data/holdout/` + `manifest_100_verified.json`.
- `search_and_download_task7_battery_candidates.py` : tải ảnh pin (Task 7). **Input**: query pin. **Output**: `data/raw/task7_battery/` + manifest.
- `fetch_additional_valid_task7_batteries.py` : bổ sung pin không trùng. **Input**: manifest hiện có. **Output**: ảnh mới + manifest cập nhật.
- `expand_task7_battery_candidates.py` : augment ảnh pin. **Input**: `data/raw/task7_battery/`. **Output**: `data/expanded/task7_battery/` + manifest.
- `search_and_download_task8a_candidates.py` : tải ảnh cho 10 lớp (Task 8‑a). **Input**: query 10 lớp. **Output**: `data/raw/task8a/` + manifest.
- `expand_task8a_candidates.py` : augment dataset 10 lớp. **Input**: `data/raw/task8a/`. **Output**: `data/expanded/task8a/` + manifest.
- `fetch_task8_multi_source_supplement.py` : bổ sung từ Wikimedia/Flickr. **Input**: manifest Task 8‑a. **Output**: ảnh mới trong `data/raw/task8a/` + manifest.
- `acquire_task8_wave2_large_batch.py` : lấy batch lớn (~3000) từ OpenImages/TACO. **Input**: `data/raw/task8a/`. **Output**: `data/raw/task8_wave2/` + manifest.
- `acquire_task8d_pilot_and_candidates.py` : tạo pilot (~150/img/lớp). **Input**: list candidate wave2. **Output**: `data/pilot/task8d/` + manifest.
- `acquire_scarce_classes_8e.py` : tách lớp hiếm. **Input**: thống kê wave2. **Output**: `data/scarce/` + manifest.
- `acquire_and_qa_task8f_scarce_classes.py` : QA tập hiếm. **Input**: `data/scarce/`. **Output**: `manifest_scarce_f.json`.
- `acquire_and_qa_task8g_large_scale.py` : thống kê QA quy mô lớn. **Input**: wave2. **Output**: `manifest_large_g.json`.
- `acquire_task8h_scarce_classes.py` : lọc sạch tập hiếm. **Input**: QA‑cleaned scarce set. **Output**: `data/clean/scarce/` + manifest.
- `pilot_and_acquire_task8e_scale.py` : cân bằng pilot (~200/img/lớp). **Input**: pilot + scarce. **Output**: `data/pilot_scaled/` + manifest.
- `prepare_acquisition_pilot.py` : tạo cấu trúc thư mục pilot và manifest.
- `supplement_task8d_wikimedia_categories.py` : thêm ảnh Wikimedia cho các category thiếu.
- `supplement_task8e_to_1100.py` : bổ sung tới 1100 ảnh.
- `verify_wikimedia_candidates.py` : audit license, độ phân giải, hash; xuất `wikimedia_audit.csv`.
- `import_and_qa_roboflow_battery.py` : giải nén ZIP Roboflow battery, QA. **Output**: `data/roboflow/battery/` + manifest.
- `ingest_roboflow_battery_export.py` : tạo layout chuẩn `data/detection/battery/` + hash CSV.
- `field_capture_import_and_qa.py` : import ảnh thực địa, chuẩn hoá EXIF, kiểm tra blur. **Output**: `data/field/` + QA JSON.
- `collect_real_detection_data.py` : tạo CSV manifest thực địa.
- `collect_real_detection_v2.py` : dedup bằng pHash, tạo manifest v2.
- `build_expansion_source_catalog.py` : tạo catalog YAML nguồn mở rộng.
- `stage_phase4e_whitelist_candidates.py` : lọc whitelist chất lượng cao, CSV.
- `stage_whitelisted_pilot_images.py` : tạo symlink whitelist vào `data/whitelist_pilot/` + manifest.
