# Description of files in Layer 1 (Data Acquisition)

## layer_1_data_acquisition/01_download_datasets_chuan_va_pilot/
- **download_datasets.py**
  - *Input*: Optional `--output-dir` (default `data/external/`).
  - *Output*: Downloads pinned Kaggle datasets `vn_trash` and `garbage_v2` into `data/external/<dataset>/`. Creates a manifest of layout roots.
- **download_100_waste_images.py**
  - *Input*: Pre‑defined list of 100 search queries for the 10 classes.
  - *Output*: 100 diverse waste images saved in `data/holdout/` and a JSON manifest `reports/qa_acceptance/manifest_100_anh_online.json`.
- **download_and_qa_minibatch01.py**
  - *Input*: Images in `data/raw/` produced by `download_datasets.py`.
  - *Output*: Validated images (SHA‑256, pHash) stored in `data/processed/minibatch01/` and a QA manifest `reports/qa_acceptance/minibatch01_manifest.json`.
- **download_and_scan_test_images.py**
  - *Input*: Images in `data/holdout/`.
  - *Output*: CSV report `reports/qa_acceptance/holdout_scan_report.csv` containing checksum, dimensions, format and any errors.
- **search_candidates.py**
  - *Input*: Hard‑coded search queries for each waste class.
  - *Output*: JSON file `reports/qa_acceptance/candidate_urls.json` with up to 50 candidate URLs per query.
- **test_queries.py**
  - *Input*: `queries.yaml` defining query strings.
  - *Output*: PyTest assertions confirming each query returns ≥5 URLs; no runtime artifact generated.
- **verify_and_download_candidates_100.py**
  - *Input*: `reports/qa_acceptance/candidate_urls.json`.
  - *Output*: 100 vetted images saved to `data/holdout/` and an updated manifest `reports/qa_acceptance/manifest_100_verified.json`.

## layer_1_data_acquisition/02_cao_va_tim_kiem_theo_dot/
- **search_and_download_task7_battery_candidates.py**
  - *Input*: Battery‑specific queries.
  - *Output*: ~200‑300 battery images in `data/raw/task7_battery/` and `reports/qa_acceptance/manifest_task7.json`.
- **fetch_additional_valid_task7_batteries.py**
  - *Input*: Existing `manifest_task7.json`.
  - *Output*: Additional non‑duplicate battery images appended to the same directory and manifest.
- **expand_task7_battery_candidates.py**
  - *Input*: Images in `data/raw/task7_battery/`.
  - *Output*: Augmented versions (rotate, flip, brightness) stored in `data/expanded/task7_battery/` with `manifest_task7_expanded.json`.
- **search_and_download_task8a_candidates.py**
  - *Input*: 10‑class query list.
  - *Output*: Raw images for all classes in `data/raw/task8a/` and `manifest_task8a.json`.
- **expand_task8a_candidates.py**
  - *Input*: `data/raw/task8a/`.
  - *Output*: Augmented dataset in `data/expanded/task8a/` with `manifest_task8a_expanded.json`.
- **fetch_task8_multi_source_supplement.py**
  - *Input*: `manifest_task8a.json`.
  - *Output*: Additional images from Wikimedia/Flickr merged into `data/raw/task8a/` and updated manifest.
- **acquire_task8_wave2_large_batch.py**
  - *Input*: `data/raw/task8a/`.
  - *Output*: Large batch (≈3000 images) from OpenImages/TACO stored in `data/raw/task8_wave2/` + `manifest_task8_wave2.json`.
- **acquire_task8d_pilot_and_candidates.py**
  - *Input*: Candidate list from `task8_wave2`.
  - *Output*: Pilot subset (≈150 images per class) in `data/pilot/task8d/` and `manifest_pilot_task8d.json`.
- **acquire_scarce_classes_8e.py**
  - *Input*: Image counts per class from `task8_wave2`.
  - *Output*: Scarc‑class collection (≈50‑100 images per rare class) in `data/scarce/` and `manifest_scarce_8e.json`.
- **acquire_and_qa_task8f_scarce_classes.py**
  - *Input*: `data/scarce/`.
  - *Output*: QA report `reports/qa_acceptance/manifest_scarce_f.json` (checks annotation format, blur, duplicate).
- **acquire_and_qa_task8g_large_scale.py**
  - *Input*: Full `task8_wave2` dataset.
  - *Output*: Large‑scale QA statistics `reports/qa_acceptance/manifest_large_g.json`.
- **acquire_task8h_scarce_classes.py**
  - *Input*: QA‑cleaned scarce set from `task8f`.
  - *Output*: Cleaned scarce dataset in `data/clean/scarce/` and final manifest `manifest_scarce_h.json`.
- **pilot_and_acquire_task8e_scale.py**
  - *Input*: Pilot set and scarce set.
  - *Output*: Balanced pilot dataset (`data/pilot_scaled/`) with ~200 images per class; manifest `manifest_pilot_scaled.json`.
- **prepare_acquisition_pilot.py**
  - *Input*: Lists of selected images.
  - *Output*: Structured folder tree `data/pilot/<class>/` and `manifest_pilot.json`.
- **supplement_task8d_wikimedia_categories.py**
  - *Input*: `manifest_task8d.json`.
  - *Output*: Additional Wikimedia images per missing category; updated manifest.
- **supplement_task8e_to_1100.py**
  - *Input*: `manifest_task8e.json` (~1000 images).
  - *Output*: Extra images to reach 1100 total, saved in same folder; new manifest `manifest_task8e_1100.json`.
- **verify_wikimedia_candidates.py**
  - *Input*: `candidates_wikimedia.json`.
  - *Output*: CSV audit `wikimedia_audit.csv` (license, resolution, hash) and filtered candidate list.

## layer_1_data_acquisition/03_ingestion_va_thu_thap_thuc_dia/
- **import_and_qa_roboflow_battery.py**
  - *Input*: Roboflow export ZIP for battery images.
  - *Output*: Extracted dataset in `data/roboflow/battery/` and QA manifest `roboflow_battery_qa.json`.
- **ingest_roboflow_battery_export.py**
  - *Input*: Same ZIP file.
  - *Output*: Canonical layout `data/detection/battery/` and hash map `roboflow_battery_hashes.csv`.
- **field_capture_import_and_qa.py**
  - *Input*: Raw field capture images (`field_capture/`).
  - *Output*: Cleaned set `data/field/` with EXIF corrected, blur‑checked; QA JSON `field_capture_qa.json`.
- **collect_real_detection_data.py**
  - *Input*: `data/field/`.
  - *Output*: CSV `real_detection_manifest.csv` containing file paths, size, SHA‑256, class.
- **collect_real_detection_v2.py**
  - *Input*: `real_detection_manifest.csv`.
  - *Output*: Deduplicated manifest `real_detection_v2.json` (pHash clustering).
- **build_expansion_source_catalog.py**
  - *Input*: List of source URLs and version identifiers.
  - *Output*: YAML catalog `catalog_expansion_sources.yaml` describing each source, license, and version.
- **stage_phase4e_whitelist_candidates.py**
  - *Input*: Candidate list `candidate_whitelist.json`.
  - *Output*: Whitelist CSV `whitelist_phase4e.csv` (high‑quality images) for Phase 4E.
- **stage_whitelisted_pilot_images.py**
  - *Input*: `whitelist_phase4e.csv`.
  - *Output*: Symlinked images in `data/whitelist_pilot/` and manifest `manifest_whitelist_pilot.json`.
