# Layer 3 – Huấn luyện và đánh giá mô hình

## 01. Chuẩn bị và kiểm tra mô hình

- audit_backbone_transfer.py: Kiểm tra quá trình chuyển backbone.
- inspect_backbone_transfer.py: Xuất báo cáo backbone sau chuyển đổi.
- import_ecovision_checkpoint.py: Chuyển checkpoint Ecovision sang định dạng TensorFlow chuẩn.
- diagnose_env_imports.py: Kiểm tra môi trường Python và lỗi phụ thuộc.
- materialize_and_verify_pilot_v3_task6.py: Chuẩn bị và xác thực dữ liệu pilot task 6.
- recompile_clean_bytecode.py: Biên dịch lại bytecode Python.
- verify_training_dry_run_environment.py: Kiểm tra môi trường huấn luyện thử.
- verify_yolo_dataloader_batches.py: Kiểm tra các batch dữ liệu YOLO.
- verify_yolo_v3_compatibility.py: Kiểm tra khả năng tương thích YOLOv3.
- inspect_checkpoints_detailed.py: Kiểm tra thông tin chi tiết checkpoint.

## 02. Huấn luyện mô hình

- train_official_mobilenetv3.py: Huấn luyện mô hình phân loại MobileNetV3.
- run_task6_e3_pilot_training.py: Huấn luyện mô hình pilot task 6.
- train_detection_v2.py: Huấn luyện mô hình phát hiện đối tượng phiên bản 2.
- run_experiment_matrix.py: Chạy nhiều thí nghiệm và tổng hợp kết quả.

## 03. Đánh giá và so sánh mô hình

- compare_eval_v1_vs_v2.py: So sánh kết quả đánh giá phiên bản 1 và 2.
- run_current_baseline_eval.py: Đánh giá mô hình baseline.
- eval_20_targets.py: Đánh giá mô hình trên 20 ảnh mục tiêu.
- evaluate_and_compare_e1_vs_e3_task6.py: So sánh kết quả thí nghiệm E1 và E3.
- evaluate_final_test.py: Đánh giá tổng thể trên tập test cuối.
- re_evaluate_from_raw_json.py: Tính lại metrics từ kết quả dự đoán JSON.
- reproduce_validation.py: Tái thực hiện kiểm tra trên tập validation.
- verify_20_targets.py: Xác thực bộ 20 ảnh mục tiêu.

## 04. Demo và kiểm tra thực nghiệm

- run_quick_demo_comparison.py: Tạo hình ảnh so sánh nhanh giữa hai demo.
- run_yolov8n_demo_100.py: Chạy YOLOv8n trên 100 ảnh demo.
- reproduce_demo_image17.py: Tái tạo kết quả dự đoán trên ảnh demo 17.
- reproduce_box_count_discrepancy.py: Kiểm tra sai lệch số lượng bounding box.
- inspect_battery_pred.py: Phân tích chi tiết dự đoán đối tượng pin.
- run_smoke_test.py: Kiểm tra nhanh toàn bộ pipeline.
- run_smoke_test_v2.py: Chạy phiên bản smoke test cải tiến.

## 05. Đo hiệu năng mô hình

- benchmark_classifier_runtime.py: Đo thời gian chạy mô hình phân loại.
- benchmark_inference.py: Đo độ trễ suy luận của mô hình.

Tóm lại: Layer 3 tiếp nhận dữ liệu đã chuẩn hóa từ Layer 2, chuẩn bị môi trường, huấn luyện các mô hình AI, đánh giá độ chính xác bằng các chỉ số phù hợp, so sánh thí nghiệm và đo tốc độ suy luận để lựa chọn mô hình phù hợp nhất.
