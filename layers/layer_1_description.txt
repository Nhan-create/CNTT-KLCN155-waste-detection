# Mô tả các file trong Layer 1 – Thu thập dữ liệu

## 01_download_datasets_chuan_va_pilot
- **download_datasets.py**
  - *Đầu vào*: Tùy chọn `--output-dir` (mặc định `data/external/`).
  - *Đầu ra*: Tải và giải nén 2 dataset Kaggle (`vn_trash`, `garbage_v2`) vào `data/external/<dataset>/`. Tạo manifest ghi vị trí layout.
- **download_100_waste_images.py**
  - *Đầu vào*: Danh sách 100 query tìm kiếm (10 lớp).
  - *Đầu ra*: 100 ảnh đa dạng được lưu trong `data/holdout/` và file JSON manifest `reports/qa_acceptance/manifest_100_anh_online.json`.
- **download_and_qa_minibatch01.py**
  - *Đầu vào*: Ảnh thô trong `data/raw/` do `download_datasets.py` tạo.
  - *Đầu ra*: Ảnh đã kiểm tra SHA‑256, pHash được lưu vào `data/processed/minibatch01/` và manifest QA `reports/qa_acceptance/minibatch01_manifest.json`.
- **download_and_scan_test_images.py**
  - *Đầu vào*: Ảnh trong `data/holdout/`.
  - *Đầu ra*: Báo cáo CSV `reports/qa_acceptance/holdout_scan_report.csv` chứa checksum, kích thước, định dạng và lỗi (nếu có).
- **search_candidates.py**
  - *Đầu vào*: Các query hard‑code cho từng lớp rác.
  - *Đầu ra*: File JSON `reports/qa_acceptance/candidate_urls.json` với tới 50 URL mỗi query.
- **test_queries.py**
  - *Đầu vào*: `queries.yaml` mô tả các chuỗi query.
  - *Đầu ra*: Kiểm thử PyTest xác nhận mỗi query trả về ≥5 URL; không tạo file output.
- **verify_and_download_candidates_100.py**
  - *Đầu vào*: `reports/qa_acceptance/candidate_urls.json`.
  - *Đầu ra*: 100 ảnh đã qua kiểm tra lưu vào `data/holdout/` và manifest cập nhật `reports/qa_acceptance/manifest_100_verified.json`.

## 02_cao_va_tim_kiem_theo_dot
- **search_and_download_task7_battery_candidates.py** – Tải ~200‑300 ảnh pin, đầu ra `data/raw/task7_battery/` + manifest `reports/qa_acceptance/manifest_task7.json`.
- **fetch_additional_valid_task7_batteries.py** – Thêm ảnh pin không trùng vào cùng thư mục và manifest.
- **expand_task7_battery_candidates.py** – Tạo dữ liệu tăng cường (rotate, flip, brightness) trong `data/expanded/task7_battery/` + manifest `manifest_task7_expanded.json`.
- **search_and_download_task8a_candidates.py** – Tải ảnh thô cho 10 lớp, đầu ra `data/raw/task8a/` + `manifest_task8a.json`.
- **expand_task8a_candidates.py** – Tăng cường dataset `data/expanded/task8a/` + `manifest_task8a_expanded.json`.
- **fetch_task8_multi_source_supplement.py** – Kéo ảnh bổ sung từ Wikimedia/Flickr, ghép vào `data/raw/task8a/` và cập nhật manifest.
- **acquire_task8_wave2_large_batch.py** – Lấy ~3000 ảnh từ OpenImages/TACO, lưu `data/raw/task8_wave2/` + `manifest_task8_wave2.json`.
- **acquire_task8d_pilot_and_candidates.py** – Chọn pilot ~150 ảnh mỗi lớp, lưu `data/pilot/task8d/` + `manifest_pilot_task8d.json`.
- **acquire_scarce_classes_8e.py** – Tách các lớp hiếm (≈50‑100 ảnh) vào `data/scarce/` + `manifest_scarce_8e.json`.
- **acquire_and_qa_task8f_scarce_classes.py** – QA cho tập hiếm, đầu ra `reports/qa_acceptance/manifest_scarce_f.json`.
- **acquire_and_qa_task8g_large_scale.py** – Thống kê QA quy mô lớn, đầu ra `reports/qa_acceptance/manifest_large_g.json`.
- **acquire_task8h_scarce_classes.py** – Lọc tập hiếm sạch, lưu `data/clean/scarce/` + `manifest_scarce_h.json`.
- **pilot_and_acquire_task8e_scale.py** – Cân bằng pilot (≈200 ảnh/lớp), lưu `data/pilot_scaled/` + `manifest_pilot_scaled.json`.
- **prepare_acquisition_pilot.py** – Tổ chức cấu trúc thư mục `data/pilot/<class>/` và tạo `manifest_pilot.json`.
- **supplement_task8d_wikimedia_categories.py** – Thêm ảnh Wikimedia cho các category thiếu, cập nhật manifest.
- **supplement_task8e_to_1100.py** – Bổ sung ảnh để đạt 1100 ảnh, cập nhật manifest `manifest_task8e_1100.json`.
- **verify_wikimedia_candidates.py** – Kiểm tra license, độ phân giải, hash; xuất CSV `wikimedia_audit.csv` và danh sách lọc.

## 03_ingestion_va_thu_thap_thuc_dia
- **import_and_qa_roboflow_battery.py** – Giải nén ZIP Roboflow battery, tạo dataset `data/roboflow/battery/` và manifest QA `roboflow_battery_qa.json`.
- **ingest_roboflow_battery_export.py** – Tạo layout chuẩn `data/detection/battery/` và file hash `roboflow_battery_hashes.csv`.
- **field_capture_import_and_qa.py** – Nhập ảnh thực địa, chuẩn hoá EXIF, kiểm tra blur, đầu ra `data/field/` + `field_capture_qa.json`.
- **collect_real_detection_data.py** – Thu thập siêu dữ liệu ảnh thực địa, xuất CSV `real_detection_manifest.csv`.
- **collect_real_detection_v2.py** – Loại bỏ trùng lặp bằng pHash, tạo manifest dedup `real_detection_v2.json`.
- **build_expansion_source_catalog.py** – Tạo catalog YAML `catalog_expansion_sources.yaml` mô tả nguồn, license, version.
- **stage_phase4e_whitelist_candidates.py** – Lọc danh sách whitelist chất lượng cao, xuất CSV `whitelist_phase4e.csv`.
- **stage_whitelisted_pilot_images.py** – Tạo symlink ảnh whitelist vào `data/whitelist_pilot/` và manifest `manifest_whitelist_pilot.json`.
